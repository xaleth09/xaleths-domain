# PW-01 (`public/pw-01.html` + `public/pw-01-assets/`)

These files are **build output**, not source. Never edit them by hand.

- Source of truth: the private `xaleth09/pool-watcher` repo
  (`apps/admin-dashboard` builds the single-file `pw-01.html`;
  `stage-assets.mjs` produces `pw-01-assets/` — ML model weights + ONNX
  runtime, each file < 25MB per Cloudflare's per-asset cap).
- The full build/verify/deploy procedure — including the BUILD-tag
  discipline and when assets need re-copying — is
  **`pool-watcher/docs/deploy.md`**. Follow it; update it there when the
  process changes.
- This repo's role is static hosting only: no code here imports
  pool-watcher, and the worker serves HTML with `Cache-Control: no-cache`
  (so a merged deploy shows on next load) while assets use default caching.
- The artifact is deliberately stealth-listed (unlabeled card "PW-01",
  noindex). Keep anything describing what it is OUT of `public/` — this
  docs directory is not served.
